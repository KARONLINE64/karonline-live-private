# KaronlineLive

Premier prototype statique de KaronlineLive, compatible avec GitHub Pages.

## Lancer localement

Depuis ce dossier, lancer un serveur HTTP statique :

```powershell
py -m http.server 8000
```

Puis ouvrir http://localhost:8000/ dans un navigateur. Le catalogue de test est dans `data/catalogue.json`. Aucun serveur LAN ou acces au dossier Windows `SERVER` n'est utilise.
