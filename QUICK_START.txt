1. Connexion → Aller sur vos domaines
2. Chercher: karonlinelive.com
3. Gérer → DNS
4. Modifier les enregistrements A:

   ┌────────────────────────────────────────────────────────────┐

   ├───────┼───────────────────┼────────────────────────┼───────┤

   │ A     │ karonlinelive.com │ 185.199.109.153        │ DNS only │

   │ A     │ karonlinelive.com │ 185.199.111.153        │ DNS only │

   └────────────────────────────────────────────────────────────┘

   Ne pas mettre karonlinelive.com ou www dans un Cloudflare Tunnel.
   Le tunnel Cloudflare doit etre reserve a api.karonlinelive.com.

6. ⏳ Attendre 5-30 min (propagation DNS)

⚠️  RÉSOLUTION DE PROBLÈMES
───────────────────────────────────────────────────────────────────

❌ "karonlinelive.com" ne fonctionne pas
   → Attendre propagation DNS (30 min max)
   → Vérifier nslookup karonlinelive.com

❌ "HTTPS not available"
   → GitHub Pages génère le certificat (5-10 min après custom domain)
   → Tenter https:// plutôt que http://

❌ "Serveur LAN indisponible" même serveur lancé
   → Vérifier: python lan_server.py --port 8765 est ACTIF
   → Vérifier: SERVER/ existe et contient des .mp4

❌ "KaronlineBox téléchargement échoue"
   → Placer setup.exe ici: C:\Users\...\KaronlineKj\setup.exe
   → Ou: C:\Users\...\KARONLINEKJ_V1.1_BUILD\setup.exe

❌ Demandes ne s'affichent pas dans KaronlineBox
   → Vérifier port 8766 est disponible
   → Vérifier KaronlineBox est lancée
   → Vérifier: python lan_server.py fonctionne
